# History

Design rationale, implementation narratives, and the original
open-source-readiness audit that shaped the project. These are
historical reference material, not user documentation.

- `critiques/` — adversarial review of early design decisions
  (architecture, parsing, search, storage). Read before proposing
  structural changes.
- `PHASE1.md`, `PHASE1B.md`, `PHASE1C.md`, `PLAN.md` — implementation
  narratives for the phased build.
- `OPEN_SOURCE_READINESS.md` — the original release-readiness audit
  (superseded; kept for provenance).
